Nạp file Price Check

Chọn file Excel Price Check (chỉ để lấy danh sách sản phẩm và giá FJM, bạn chọn sản phẩm cần check ở mục Cần check). Tool tự tìm dòng tiêu đề (Barcode, Item Code, Item Name, Unit, DATE, FJM_Normal Selling Price, FJM_Promotion Selling Price) và ưu tiên sheet tên Price Check. File CSV đơn giản (Barcode, Tên, Giá) cũng đọc được.

Danh sách sản phẩm và giá đã ghi lưu trong trình duyệt của máy này. Nhớ Xuất CSV sau mỗi buổi. Sao lưu JSON để chuyển dữ liệu sang máy khác hoặc gộp dữ liệu nhiều người.
